# Twenty-minute Grace Valley playtest

This is the remaining human check for M1. It measures clarity and pacing as well as stability. The automated scenarios and SDL soak test cover only part of that goal.

## Session

1. Start the current Debug build and set a 20-minute timer.
2. Build a connected neighborhood of at least three homes.
3. Place a pantry and inspect its gold coverage preview before clicking.
4. Remove a road that serves homes, observe the red access warnings, then reconnect it.
5. Expand toward the pond and woods. Note whether their rules are clear before placing.
6. Build enough services to run short of volunteers. Press `V` and watch coverage change.
7. Host a gathering with `E` and a food drive with `F` when available.
8. Try the camera controls and continue playing until the timer ends.

## Record

- Did the game crash, freeze, or show a rendering problem? When?
- Which building, color, or number needed explanation?
- Was the first 10 minutes too slow, too fast, or comfortable?
- Did funds or volunteers create an interesting choice?
- What did you want to do that the game did not allow?

M1 can close when the 20-minute session runs without a crash and placement, costs, and feedback make sense to a new player. Log follow-up issues in this file or the project issue tracker.
