# Contributing

1. Build from the CMake presets in the root README.
2. Keep game rules in `src/core` and platform/rendering code in `src/game`.
3. Add tests for new simulation rules and run `ctest`.
4. Document any new third-party dependency, version, license, and asset rights.
5. Prefer small features that can be played and evaluated before expanding the simulation.

Use descriptive commit messages. Discuss major changes to the game's tone or scope before committing to large amounts of content.
